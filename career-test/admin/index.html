Сурагчдын тестийн хүсэлт

Хяналтын самбар

Хүлээн авсан хүсэлтийг шалгаж, шаардлагатай бол буцаана. Зөвшөөрсөн тайлангийн автомат илгээлт PDF болон и-мэйл холболт хийгдсэний дараа идэвхжинэ.

Хөгжүүлэлтийн төлөв: Хүсэлт хадгалах болон админы хяналт серверт холбогдсон. PDF тайлан үүсгэх, Resend и-мэйл илгээлтийн pipeline одоогоор холбогдоогүй. Энэ самбарыг production хяналтад хараахан ашиглахгүй.
