# Holland RIASEC — үр дүнгийн тайлангийн баталсан дизайн шаардлага

Энэ баримт нь хэрэглэгчийн илгээсэн Тест 1, Тест 2-ын жишээ зураг болон чатанд өгсөн баталгаажуулалтад үндэслэв. Энэ нь дизайны шаардлага болохоос бүрэн хэрэгжсэн UI биш.

## Нийтлэг зохион байгуулалт (Тест 1 ба 2)

1. Хуудасны дээд хэсэгт тестийн дугаар, нэр, үндсэн гарчиг, хэмжүүрийн тайлбар.
2. Дараагийн хэсэгт “Хамгийн өндөр оноо” болон “Тэргүүлж буй чиглэл” summary card.
3. Төв хэсэгт RIASEC зургаан өнцөгт radar график.
4. Доод хэсэгт R, I, A, S, E, C зургаан өнгөт хэвтээ онооны мөр; онооны бар 0–18 хүрээнд харьцаагаар дүүрнэ.
5. Тайлбарын callout.
6. Footer-д брэнд/тайлангийн нэр болон хуудасны дугаар.

## Radar графикийн заавал мөрдөх дүрэм

- Цэгийн байрлал нь тухайн хэв шинжийн бодит оноогоор тогтоно.
- Дугуй тэмдэглэгээний хэмжээ нь оноотой шууд пропорциональ байна.
- Хамгийн өндөр оноо авсан хэв шинжийн дугуй хамгийн том.
- Бага оноотой хэв шинжийн дугуй жижиг.
- Оноо тэнцүү хэв шинжүүдийн дугуйн хэмжээ яг ижил.
- Дугуйн өнгө RIASEC хэв шинжийн тогтсон өнгөтэй таарна.
- Дугуйн хэмжээг тогтмол том/жижиг болгохгүй; сурагч бүрийн оноогоор динамикаар тооцно.
- Онооны бар болон radar график хоёулаа нэг ижил бодит онооны объект/утгыг ашиглах ёстой.

## Баталгаажуулалт ба хэрэгжүүлэлт

Энэ баримт нь хэрэгжүүлэлтийн acceptance criteria. Кодод нэвтрүүлсний дараа:
- Онооны өгөгдөл өөрчлөгдөхөд radar-ийн цэгийн байрлал, дугуйн хэмжээ болон bar зэрэг шинэчлэгдэж буйг шалгах.
- Тэнцүү онооны цэгийн радиус тэнцүү эсэхийг unit/browser test-ээр батлах.

- Өмнө байгаа асуулт, код, оноолол, pair order-д хүрэхгүй.

## Тест 3 — мэргэжлийн хэв шинжийн үр дүнгийн загвар

Тест 3-ын тайлан нь Тест 1/2-ын тайлантай ижил брэндийн өнгө, типографик, зай авалт, зургаан өнцөгт radar хэлбэрийг хадгална. Харин хэмжүүр нь 42 сонголт тул 0–42 хүрээнд дүрслэгдэнэ.

1. **Толгой хэсэг:** “Таны мэргэжлийн хэв шинж” гэсэн гарчиг; “42 хос мэргэжлээс хийсэн сонголтын үр дүн” гэсэн тайлбар.
2. **Товч дүгнэлт:** онооны дарааллаар хамгийн өндөр оноотой хэв шинжийг “Ерөнхий мэргэжлийн хэв шинж”, дараагийн хоёр өндөр оноотой хэв шинжийг “Дагалдах хэв шинж” гэж харуулна. Хэв шинж бүрийн оноог x / 42 хэлбэрээр бичнэ. Байр эзлэх оноо тэнцсэн тохиолдолд rank(arr)-ийн гуравдугаар байрын cutoff-той тэнцсэн бүх хэв шинжийг хадгалж, дур мэдэн нэгийг хасахгүй.
3. **RIASEC radar:** R, I, A, S, E, C зургаан тэнхлэгтэй зургаан өнцөгт. Утга 0–42; цэгийн байрлал болон диаметр онооноос динамикаар хамаарна. Оноо тэнцүү цэгүүд яг ижил диаметртэй, 0 оноотой цэг харагдахуйц жижиг хамгийн бага тэмдэглэгээтэй байна.
4. **Онооны мөр:** зургаан хэв шинжийн оноог x / 42 хэлбэрээр харуулна; мөрийн дүүргэлт x / 42 × 100% байна. Radar болон мөр ижил test3 онооны объект ашиглана.
5. **Хэв шинжийн дүгнэлт:** “Ерөнхий мэргэжлийн хэв шинж” болон “Дагалдах хэв шинж” гэсэн хоёр хэсгээр онооны эрэмбийг харуулна. “Таны сонгосон мэргэжлүүд” гэсэн тусдаа жагсаалт/хэсэг оруулахгүй.
6. **Тайлбарын callout:** хамгийн өндөр оноотой хэв шинж(үүд) нь энэ 42 хос сонголтын хүрээнд илүү олон удаа сонгогдсоныг тайлбарлана. Энэ нь мэргэжлийн эцсийн шийдвэр, чадварын шалгалт, онош биш гэдгийг тодорхой хэлнэ.
7. **Footer:** брэнд/тайлангийн нэр болон хуудасны дугаар.

### Тест 3-ын өгөгдөл ба хязгаарлалт

- Эх материалын 42 хосын дараалал, мэргэжлийн нэр, хэв шинжийн код (1=R, 2=I, 3=A, 4=S, 5=E, 6=C)-ийг яг хэвээр хадгална.
- Сонгосон мэргэжил бүр тухайн мөрийн эх материалд өгөгдсөн кодоор нэг оноо нэмнэ. Нийт сонголт 42; зургаан бүлгийн нийлбэр заавал 42 байна.
- Гуравдугаар байрын cutoff-той тэнцсэн бүх хэв шинжийг харуулна.
- Тест 3-ын raw оноог Тест 1/2-ын 0–18 оноотой нэмж, дундажлан эсвэл өөрөө зохиосон жингээр нэгтгэхгүй.
- Тайланд сонгосон мэргэжлүүдийн нэрсийн жагсаалт гаргахгүй; ерөнхий болон дагалдах хэв шинжийг онооны эрэмбээр харуулна.
- Preview дээрх бүх оноо, мэргэжлийн жагсаалт нь зөвхөн зохиомол жишээ бөгөөд сурагчийн бодит үр дүн биш.
