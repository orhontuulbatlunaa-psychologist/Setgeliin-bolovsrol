# Төслийн шилжүүлгийн тэмдэглэл — Сэтгэлийн боловсрол

> Дараагийн чатад ажлыг үргэлжлүүлэхдээ эхлээд энэ файлыг унш. Энэ баримт нь батлагдсан шийдвэр, ажлын байрлал, хязгаарлалтыг нэг дор хадгалах зорилготой.

## 1. Төслийн үндсэн мэдээлэл

- Repository: `orhontuulbatlunaa-psychologist/Setgeliin-bolovsrol`
- Ажлын branch: `feature/holland-riasec-integration`
- Холбогдох PR: [PR #1](https://github.com/orhontuulbatlunaa-psychologist/Setgeliin-bolovsrol/pull/1)

- Production URL: https://setgeliin-bolovsrol-jthscswdi.vercel.app/

### Заавал мөрдөх хамгаалалт

1. **`main` branch руу merge хийхгүй.** Хэрэглэгч production өөрчлөлт хийхийг зөвшөөрөөгүй.
2. Бүх шинэчлэл зөвхөн `feature/holland-riasec-integration` branch дээр хийгдэнэ.
3. Production сайт шинэчлэгдсэн гэж мэдэгдэхгүй. Зөвхөн бодитоор шалгасан зүйлээ тайлагнана.
4. Preview URL байгаа нь тухайн шинэ commit амжилттай deploy болсон эсвэл браузераар шалгагдсан гэсэн баталгаа биш. Браузерын E2E шалгалт хийгдээгүй бол тодорхой хэл.
5. Батлагдсан хуудсын агуулга, дизайн, логикийг хэрэглэгчийн зөвшөөрөлгүй өөрчлөхгүй.
6. Шинэ чатад энэ файлыг эхлээд уншиж, аль хэдийн хийгдсэн ажлыг давтаж эхлүүлэхгүй.

## 2. Батлагдсан тайлангийн дараалал

Хэрэглэгч дараах дарааллыг тодорхой баталсан. **Энэ дарааллыг өөрчилж болохгүй.**

1. Нийтлэг тайлангийн нүүр хуудас.
2. **ЗУРГААН ХЭВ ШИНЖИЙГ ОЙЛГОХ НЬ** — тайлангийн нүүрний яг дараа.
3. Тест 1-ийн үр дүнгийн хуудас.
4. Тест 2-ын үр дүнгийн хуудас.
5. Тест 3-ын үр дүнгийн хуудас.
6. Сонирхол, чадавх, мэргэжлийн хэв шинжийн харьцуулсан дүгнэлт.

Нүүр хуудасны нийтлэг загварыг бүх гурван тестийн тайланд ашиглана. Хэрэглэгчийн өгсөн/баталсан нүүрний эх загварыг эх сурвалж гэж үз.

## 3. Батлагдсан хуудаснууд ба файлууд

### Нийтлэг нүүр хуудас
- Хэрэглэгчийн өмнө өгсөн, баталсан нийтлэг тайлангийн нүүрний загварыг ашиглана.
- Нүүрэнд “Сэтгэлийн боловсрол”, 9–12 ангийн тэмдэглэгээ, RIASEC дүрслэл, “Өөрийгөө таньж, ирээдүйгээ чиглүүлье.” гарчиг, сурагчийн мэдээлэл болон тайлангийн мэдээлэл орно.
- Эх зураг/эх файлтай зөрүү гарвал өөрөө таамаглан өөрчлөхгүй.

### Харьцуулсан дүгнэлтийн хуудас
- Preview: `docs/combined_result_design_preview.html`
- Гарчиг: “СОНИРХОЛ, ЧАДВАР, МЭРГЭЖЛИЙН ХЭВ ШИНЖИЙН ХАРЬЦУУЛСАН ДҮГНЭЛТ”.
- Хэрэглэгчийн эцэслэн баталсан хувилбарын commit: `2e89ee0c25a8a1829f843f0ef115176a113738d6`
- Гурван тестийн тусдаа жижиг график, давхцуулсан харьцуулалтын график, давтамжийн жагсаалт, зонхилох ба дагалдах хэв шинжийн тайлбар, дүгнэлттэй.
- Тест бүрийн оноог тус тусад нь харуулна; өөр өөр хэмжүүрийн оноог нэмж нэгтгэхгүй.
- Гурван тестийн тус бүрийн хамгийн өндөр 3 RIASEC төрлийг сонгоно. Ингэснээр 3 × 3 = 9 байрлалыг харьцуулна.
- Зөвхөн эдгээр эхний 3-т багтсан төрлүүдийн давтамжийг тоолно. Бусад оноог давтамжид тооцохгүй.
- Хамгийн олон давтагдсан нь “мэргэжлийн зонхилох хэв шинж”; дараагийн хоёр нь “дагалдах хэв шинжүүд”.
- Тэнцсэн давтамжийн эрэмбийг бодит үр дүнд гарвал дур мэдэн шийдэхгүй; тэнцүүг ил тод харуулах эсвэл хэрэглэгчээс тодруулна.
- Загварын өнгө: Тест 1 сонирхол — clay `#bd8066`; Тест 2 чадавх — blue `#7892a3`; Тест 3 мэргэжлийн хэв шинж — green `#7c9b83`. RIASEC зургаан төрөл тус тусын өнгөтэй.
- Жижиг графикуудын “Эхний 3 · /18”, “Эхний 3 · /42” гэсэн тайлбаруудыг хассан.

## 4. RIASEC нэршлийн нэг мөр хэрэглээ

| Код | Монгол нэр |
|---|---|
| R | Бодит үйл ажиллагааг эрхэмлэгч |
| I | Судлаач, шинжээч |
| A | Уран сайхны |
| S | Нийгмийн |
| E | Ажил хэрэгч |
| C | Стандартыг баримтлагч |

Эдгээр нэршлийг тайлангийн бүх хуудсанд нэг мөр хэрэглэ. Өөр хувилбар нэршил зохиож сольж болохгүй.

## 5. Оноо, графикийн дүрэм

- Тест 1 ба Тест 2: төрөл тус бүрийн дээд оноо 18.
- Тест 3: төрөл тус бүрийн дээд оноо 42.
- Гурван тестийн оноог хооронд нь нэмж болохгүй; хэмжүүрүүдийг тус тусад нь харуул.
- Тест 1/2 radar графикийн цэгийн радиус оноонд пропорционал: `Math.max(3, score/18*13)`; радиаль байрлал мөн онооноос хамаарна.
- Тест 3-ын цэгүүд сонголтын тоог харуулна.
- Харьцуулалтын давтамжийн тооцоонд зөвхөн тест бүрийн эхний 3 төрөл орно.

## 6. Загварын чиглэл

- Тайлангийн ерөнхий мэдрэмж: цэгцтэй, мэргэжлийн, дулаан, сурагчдад ойлгомжтой.
- Суурь өнгө: дулаан цайвар цаас, цайвар ногоон/sage, шороон өнгө.
- RIASEC-ийн зургаан өнгийг тогтвортой хэрэглэ.
- Хэт чимэглэл, хэт олон жижиг тайлбар, графикийн уншигдах байдлыг бууруулах шийдлээс зайлсхий.
- Батлагдсан хуудсуудын дизайн системийг шинэ хуудсанд баримжаа болго; гэхдээ батлагдсан хуудсуудыг өөрөө шинэчилж болохгүй.

## 7. Шалгалтын төлөв ба анхаарах зүйл

- Өмнөх ажлуудад browser E2E/CI бүрэн шалгалт хийгдээгүй.
- Preview URL-уудыг бодитоор браузераар нээж шалгаагүй бол “ажиллаж байна” гэж батлахгүй.
- Сүүлийн ажлын хүрээнд зургаан хэв шинжийн HTML файл branch-д нэмэгдсэн; preview URL-ийг өгсөн боловч deploy болон browser rendering-ийг бие даан баталгаажуулаагүй.
- PR #1 нь өмнөх тэмдэглэлээр draft/open/unmerged байсан. Дараагийн чатад PR төлөвийг шалгалгүйгээр хэвээр гэж бүү батал.
- Өмнө тэмдэглэсэн commit SHA-ууд нь ажлын түүхийн баримжаа; үргэлжлүүлэхийн өмнө branch-ийн хамгийн сүүлийн төлөв, файлуудыг GitHub-оос дахин шалга.

## 8. Дараагийн чатад хийх эхний алхам

1. Энэ handoff файлыг унш.
2. `feature/holland-riasec-integration` branch дээрх хамгийн сүүлийн commit болон PR #1-ийн төлөвийг шалга.
3. Дээрх батлагдсан HTML файлууд байгаа эсэх, хамгийн сүүлийн хувилбар нь зөв эсэхийг шалга.
4. Тайлангийн нүүрний эх загвар болон бодит тайлан үүсгэх урсгалд эдгээр хуудсыг заасан дарааллаар холбох шаардлагатай эсэхийг судал. Шууд production руу бүү гарга.
5. Шинэ өөрчлөлт хийхээс өмнө хэрэглэгчийн баталсан шийдвэрүүдийг хамгаалж, зөвхөн хараахан хийгдээгүй ажлыг үргэлжлүүл.
